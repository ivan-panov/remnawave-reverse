# Hotfix 2: актуальные контейнеры и безопасное обновление

Изменения:

- новые установки используют `remnawave/backend:3` вместо `backend:2`;
- новые установки всегда выполняют `docker compose pull` перед первым запуском;
- Node и Subscription Page получают актуальные образы по тегу `latest`;
- Nginx переведён на `nginx:stable`, Caddy — на ветку `2`;
- добавлен интерактивный переход Panel 2.x → 3.x с резервной копией PostgreSQL;
- добавлен последовательный updater с healthcheck и попыткой отката образа;
- добавлен еженедельный systemd timer;
- добавлен режим пониженного потребления RAM для VPS с 1 ГБ;
- исправлены ошибочные команды вида `docker compose down <service>`;
- исправлено получение `secretKey` в актуальном API Remnawave;
- PostgreSQL не обновляется автоматическим модулем, чтобы исключить неконтролируемое обновление базы данных.
