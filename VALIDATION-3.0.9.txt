Remnawave Reverse 3.0.9 validation
Date: 2026-08-08 UTC

Fix target:
- Standalone remnawave-nginx was restarting because nginx.conf referenced /etc/nginx/ssl/<domain>/fullchain.pem while the certificate existed on the host under Certbot /etc/letsencrypt/live/<domain>/ and was not available correctly inside the container.

Changes:
- SCRIPT_VERSION=3.0.9.
- Standalone Node remnawave-nginx mounts the entire /etc/letsencrypt tree read-only.
- Standalone Node nginx.conf reads fullchain/privkey directly from /etc/letsencrypt/live/<domain>/.
- Existing standalone Node self-repair migrates legacy /etc/nginx/ssl paths.
- The repair inserts the volume specifically under services.remnawave-nginx.volumes, not merely anywhere in docker-compose.yml.
- The repair detects stale running containers by Docker mount inspection.
- docker-compose.yml and nginx.conf are backed up before migration.
- docker compose config is checked before container recreation.
- Only remnawave-nginx is force-recreated.
- After recreation, the repair checks that certificates are readable inside the container and that nginx -t succeeds.
- On failure, the old compose/nginx config is restored and recent nginx logs are printed.
- Certbot renew hook remains tied to /opt/remnanode.

Validation performed:
PASS - bash -n on all 20 shell files.
PASS - RU/EN keys for the new repair errors are present.
PASS - service-aware volume insertion test places /etc/letsencrypt only under remnawave-nginx.
PASS - volume insertion is idempotent (exactly one mount after two calls).
PASS - generated standalone Node nginx paths use /etc/letsencrypt/live/<domain>/.
PASS - legacy nginx path migration converts fullchain.pem, privkey.pem and ssl_trusted_certificate paths.
PASS - YAML parse of the representative repaired compose succeeds with PyYAML.

Not performed in this environment:
- Live Docker Engine / Docker Compose recreation on the user's VPS.
- Live nginx container start against the user's actual certificate files.
- Live Certbot renewal against Let's Encrypt.
- Live Remnawave Panel <-> Node connection.
