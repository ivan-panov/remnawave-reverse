# Автоматизация каскада VLESS IN → VLESS OUT

Модифицированная сборка добавляет в главное меню пункт:

```text
12. Серверный роутинг — каскад VLESS IN → VLESS OUT
```

## Что создаётся автоматически

На основании уже назначенных профилей двух нод модуль:

1. предлагает выбрать входную и выходную ноды;
2. предлагает выбрать inbound'ы входной ноды;
3. клонирует исходный профиль выходной ноды;
4. добавляет в клон служебный VLESS + REALITY inbound;
5. назначает клон выходной ноде, сохраняя ранее активные inbound'ы;
6. создаёт Internal Squad для служебного inbound;
7. создаёт бессрочного служебного пользователя с VLESS UUID;
8. клонирует профиль входной ноды;
9. добавляет VLESS + REALITY outbound на выходную ноду;
10. добавляет правила маршрутизации выбранных inbound'ов;
11. назначает клон входной ноде;
12. сохраняет состояние для отключения, повторного включения и удаления.

Исходные Config Profiles не редактируются и не удаляются.

## Режимы маршрутизации

- весь трафик выбранных inbound'ов через выходную ноду;
- российские IP и домены через входную ноду, остальной трафик через выходную.

## Установка

Распакуйте архив на сервере Remnawave Panel и выполните:

```bash
cd remnawave-reverse-proxy-3.0.0
chmod +x install_remnawave.sh
sudo ./install_remnawave.sh
```

После установки команда запуска:

```bash
remnawave_reverse
```

или:

```bash
rr
```

## Важное ограничение

Модуль работает через API Remnawave и не имеет SSH-доступа к выходной VPS. Поэтому системный firewall выходного сервера он изменить не может. После создания откройте выбранный TCP-порт на выходной VPS, желательно только для IP входной VPS. Например:

```bash
sudo ufw allow from ENTRY_VPS_IP to any port 8443 proto tcp comment 'Remnawave VLESS cascade'
sudo ufw status numbered
```

Если firewall управляется не UFW, добавьте эквивалентное правило в используемой системе.

## Откат и удаление

Пункт «Отключить» возвращает входной ноде исходный профиль, оставляя служебные объекты для быстрого повторного включения.

Пункт «Удалить»:

- возвращает обеим нодам исходные профили и исходный набор активных inbound'ов;
- удаляет служебного пользователя;
- удаляет Internal Squad;
- удаляет оба клонированных каскадных профиля.

Состояние хранится в:

```text
/usr/local/remnawave_reverse/cascade_vless/state.json
```

## Обновления

В этой сборке официальное автообновление исходного скрипта отключено, поскольку обновление из upstream удалило бы добавленный модуль. Для обновления сначала следует перенести изменения на новую версию исходного проекта и повторно проверить API-совместимость.
