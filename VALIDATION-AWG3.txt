Important upstream behavior
---------------------------
The upstream v5.24.0 installer does not guarantee module 3.0 on every supported host. It chooses 3.0 on x86_64 with Linux 6.7+; older kernels and some ARM/prebuilt paths may receive 2.0. This custom menu item intentionally enforces x86_64 + kernel 6.7+ and verifies the installed module so its label remains truthful.

The upstream installer currently does not enable every experimental AWG 3.0 wire feature in generated client configs. Existing AWG configuration syntax remains compatible, but header protection/content-padding/timing extensions are not automatically enabled by this integration.
