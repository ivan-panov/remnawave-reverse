# Автоматическое получение API-токена Subscription Page

Исправленная установка выполняет полный цикл автоматически:

1. запускает Remnawave Panel и ждёт готовности локального API;
2. регистрирует администратора и получает административный JWT;
3. создаёт через `POST /api/tokens` отдельный токен `subscription-page`;
4. атомарно сохраняет секрет в `/opt/remnawave/.env`:
   `REMNAWAVE_API_TOKEN=...`;
5. оставляет в Compose только ссылку `${REMNAWAVE_API_TOKEN}`, а не сам секрет;
6. пересоздаёт `remnawave-subscription-page`;
7. проверяет, что контейнер получил непустой токен и перешёл в `healthy`.

Если API не вернул токен, файл `.env` не записался или Subpage остался
неработоспособным, установка останавливается с ошибкой. Успешное завершение с
пустым `REMNAWAVE_API_TOKEN` больше не допускается.
